# Shipaton R04 Production Runbook

## Truth rule

The camera must remain on real WEXSPACE runtime for the substantive demonstration. Minimal judge-facing lower thirds, subtitles, logo and closing identifiers are allowed only as overlays on continuing runtime footage.

No slide deck is used.

## Capture sequence

1. Launch WEXSPACE Android Command Center.
2. Open **Compact Pump Skid**.
3. Advance every real execution stage:
   - Route to specialist
   - Run deterministic tool
   - Run independent verification
   - Issue evidence receipt
4. Return to Command Center.
5. Repeat the same five-stage grammar for **Mini Solar Power Station**.
6. Repeat for **Remote Link Rescue**.
7. Return to Command Center and show the shared execution fabric and WEXSPACE Pro entry point.
8. Keep runtime footage visible under the final judge overlay.

## Cinematography

- Visible Android touch points.
- Smooth real scrolling between execution receipts.
- No hard-cut to presentation slides.
- Portrait Android surface remains sharp in the center; a motion-treated derivative of the same runtime footage fills the widescreen background.
- 1920×1080, 60 fps master.
- Short cross-fades are allowed only between continuous runtime chapters.
- First thirty seconds must already demonstrate product use and the first project.

## Audio

- Narration generated from the approved script.
- Original procedural score generated during render.
- Burned English subtitles.
- No third-party copyrighted music.

## QA gates

- duration < 120 seconds
- 1920×1080
- 60 fps output
- H.264 video + AAC audio
- non-empty audio track
- three project IDs present in the production manifest
- each project contains REQUEST → SPECIALIST → TOOL → VERIFY → EVIDENCE
- no simulated success language
- final SHA-256 receipt
