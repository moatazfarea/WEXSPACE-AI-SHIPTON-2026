# WEXSPACE Studio OS — Cinematic Production Company

WEXSPACE Studio OS is not a slide generator. It is a governed production system for capturing real WEXSPACE execution and turning it into evidence-linked cinematic media.

## Operating doctrine

Every production must preserve the distinction:

`configured ≠ authorized ≠ executed ≠ verified`

Every scene is assigned a truth class:

- `LIVE_RUNTIME` — real WEXSPACE UI and real tool execution.
- `REPLAY_OF_VERIFIED_RUNTIME` — replay of a preserved verified run.
- `JUDGE_OVERLAY` — minimal explanatory overlay that does not pretend to be product runtime.
- `FORBIDDEN_SIMULATION` — fake success, fabricated purchase state, or fabricated evidence.

Shipaton R04 permits the first three classes and forbids the fourth.

## Company structure

**Executive Producer Agent** owns scope, deadline, budget and final-go/no-go.

**Director Agent** owns narrative continuity, first-30-second strength, pacing and scene priority.

**Technical Director Agent** owns the production manifest, deterministic timing and adapter routing.

**Android Capture Agent** owns emulator/device launch, visible taps, scrolling, app state and raw runtime footage.

**Cinematography Agent** owns framing, camera motion, crop/zoom and transitions without hiding runtime truth.

**Evidence Producer Agent** binds scenes to project IDs, runtime results, commits and artifacts.

**Editor Agent** assembles cuts and transitions from real captured footage.

**Audio Agent** mixes narration and original/generated audio that is cleared for use.

**Subtitle Agent** produces synchronized captions.

**Rights Agent** checks licenses and third-party notices.

**QA Agent** checks duration, frame rate, resolution, audio, scene coverage, runtime truth and prohibited simulated success.

**Release Agent** promotes only a QA-passed master and produces checksums / metadata.

## Shipaton R04 film contract

The film contains three complete micro-projects, each following the same WEXSPACE execution grammar used by serious engineering work:

`REQUEST → SPECIALIST → DETERMINISTIC TOOL → INDEPENDENT VERIFY → EVIDENCE RECEIPT`

1. Compact Pump Skid — mechanical engineering.
2. Mini Solar Power Station — energy engineering.
3. Remote Link Rescue — telecom + power, with a small dramatic/humorous beat.

No mission is presented as a deck. The camera records the real Android app while the workflow advances.

## Adapter architecture

Studio OS owns contracts, orchestration, state, evidence and QA. Engines remain replaceable adapters:

Android Emulator / ADB → runtime surface and input
FFmpeg / ffprobe → capture, edit, mux, QA
Xvfb → virtual display when needed
Playwright / Chromium → web-control and browser capture where appropriate
GitHub Actions → reproducible production worker
RevenueCat → entitlement runtime
Voice adapter → narration
Future: Remotion, Three.js, Blender, Lottie, GSAP, hardware capture nodes

The production workflow is intentionally adapter-driven rather than a monolith.
