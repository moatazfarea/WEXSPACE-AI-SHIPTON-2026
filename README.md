# WEXSPACE AI — Shipaton 2026

WEXSPACE AI is a human-governed AI execution workspace for durable, resumable and evidence-linked work.

This public repository is the Shipaton 2026 / Next Gen judge-facing project. It is intentionally isolated from the private commercial WEXSPACE repository.

## The three Shipaton missions

All three projects use the same WEXSPACE execution grammar:

**REQUEST → SPECIALIST → DETERMINISTIC TOOL → INDEPENDENT VERIFY → EVIDENCE RECEIPT**

### 01 — Compact Pump Skid
Mechanical duty-point design from flow, static lift, pipe geometry and losses to TDH, shaft power, motor candidate, an independent Haaland friction cross-check and a hash-bound evidence receipt.

### 02 — Mini Solar Power Station
Energy demand and peak load become PV array, battery and inverter capacity, followed by an independent energy-balance and storage-autonomy check.

### 03 — Remote Link Rescue
A staged telecom/power incident freezes evidence, routes telecom and power specialists, computes the critical-load recovery window and leaves consequential recovery behind a human authority boundary.

`studio-os/` contains the permanent cinematic production company architecture used to produce the submission film.

It includes:
- production company / agent fleet
- adapter registry
- production manifest
- deterministic production orchestrator
- Android runtime capture workflow
- voice/subtitle pipeline
- 60 fps FFmpeg mastering
- evidence and QA gates

The film contract forbids slide-deck demos and simulated success. The substantive video is real Android runtime with visible interactions.
